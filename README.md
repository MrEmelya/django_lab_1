# Новостной мини-портал на Django

Студенческий проект, выполненный в рамках дисциплины "Современные технологии программирования".

## Описание
Приложение реализует простой новостной портал с возможностью просмотра, добавления и чтения новостей. 
Данные хранятся в локальном JSON-файле (`news_app/data/news.json`), база данных не используется (согласно ТЗ).

## Стек
- Python 3
- Django 4.2
- Bootstrap 5 (через CDN)

## Функционал
- Главная страница со списком новостей (сортировка от новых к старым).
- Подсветка новостей, добавленных сегодня.
- Страница просмотра полной новости.
- Форма добавления новости с валидацией.
- Страница подтверждения.

## Как запустить
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
```

2. Выполните миграции (для работы админки, хоть мы её и не используем):

```
python manage.py migrate
```
3. Запустите сервер:

```
python manage.py runserver
```
4. Откройте в браузере `http://127.0.0.1:8000/`

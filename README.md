# Новостной портал на Django 

Студенческий проект, выполненный в рамках дисциплины "Современные технологии программирования".

## Описание
Приложение реализует полноценный новостной портал с системой аутентификации, базой данных (SQLite) и персонализированным управлением новостями. 
Данные теперь хранятся в БД, а не в JSON-файле.

## Стек
- Python 3
- Django 4.2
- SQLite (встроенная БД)
- Bootstrap 5 (через CDN)

## Функционал
- Регистрация пользователей (с email, именем, фамилией) и вход/выход в систему.
- Просмотр профиля и его редактирование.
- Удаление аккаунта с подтверждением (все новости пользователя удаляются вместе с аккаунтом).
- Создание новостей (доступно только авторизованным пользователям).
- Редактирование и удаление новостей (доступно только автору новости, при попытке изменить чужую — возвращается ошибка 403).
- Главная страница со списком всех новостей, пагинацией (по 3 новости на страницу) и меткой «Ваша новость» для автора.
- Валидация форм и вывод сообщений об успехе/ошибке через Django Messages.

## Как запустить локально
1. Установите зависимости:
```
   pip install -r requirements.txt
```

2. Примените миграции для создания таблиц в базе данных:

```
python manage.py makemigrations
python manage.py migrate
```
3. (Опционально) Создайте суперпользователя для доступа в админку:

```
python manage.py createsuperuser
```
4. Запустите сервер разработки:

```
python manage.py runserver
```
5. Откройте в браузере `http://127.0.0.1:8000/`

## Структура проекта

- `news_app/models.py` — модель `News` с привязкой к автору.
- `news_app/forms.py` — формы для регистрации (`UserRegisterForm`), редактирования профиля (`UserUpdateForm`) и работы с новостями (`NewsForm`).
- `news_app/views.py` — представления для CRUD операций, аутентификации и профиля.
- `news_app/templates/` — HTML-шаблоны с наследованием от `base.html`.

# Документация REST API

Базовый URL: `http://127.0.0.1:8000/api/` (или ваш адрес на Render)

## Аутентификация
Для доступа к методам создания/редактирования/удаления требуется токен.
1. Получите токен: `POST /api/token/` с JSON `{"username": "...", "password": "..."}`
2. Передавайте токен в заголовке: `Authorization: Token <ваш_токен>`

## Пользователи
- `GET /api/users/` — список пользователей.
- `POST /api/users/` — регистрация нового пользователя. Поля: `username`, `email`, `password`.

## Новости
- `GET /api/news/` — список новостей (доступна пагинация по 10 шт. и фильтрация `?author=<id>`, поиск `?search=<текст>`).
- `POST /api/news/` — создать новость (требуется авторизация). Поля: `title`, `summary`, `content`.
- `GET /api/news/<id>/` — детали новости.
- `PUT/PATCH /api/news/<id>/` — обновить новость (только автор).
- `DELETE /api/news/<id>/` — удалить новость (только автор).
